# 家中相册（网页版）

这是「家中相册」草稿的**静态版本**——给 GitHub Pages 用的：只有网页、照片和一套缩略图，没有服务端，所以放到哪儿都能直接打开。

代价是少了三件事（那些要本地跑 `node server.js` 的完整版才有）：导入照片、删除照片、以及「未识别」里刚传进来还没认领的那一摞。这一版里的「访客 / 家人」按钮也只剩个样子。

## 页面

| 地址 | 是什么 |
| --- | --- |
| `index.html` | 首页：最近一张 + 照片墙，还有「人物 / 全部 / 未识别」 |
| `person.html?id=nainai` | 个人页（id 也可以给 `yeye`、`baba`、`mama`、`xiaoman`） |
| `start.html` | 挑展示样式 → `gallery.html`（转圈的）/ `flow.html`（流动的） |
| `index.html` 右上角「展示模式」 | 同上，进去之后右上角 ⇄ 可以换 |

照片上点一下看大图（左右键翻页、Esc 关掉），右键（iPad 上按住半秒）出「打开看」。

## 照片

墙上的小图用 `thumbs/`（640 宽，快），点开看大图用 `photos/`（原图，清楚）。这些是 AI 生成的占位图，不是真照片。

## 这份文件夹怎么来的

是源码里的 `build-pages.ps1` 生成的：把 `public/` 铺到根目录、把绝对路径全改成相对路径、把两个要靠服务端的入口藏起来。**改东西请改源码，然后重新跑一遍构建**，别直接改这里。
